# PREMIUM FENSTERBAU — Архитектурные оконные системы и интерактивный конфигуратор

Демонстрационный веб-сервис премиального остекления с высокой конверсией и встроенным интерактивным SVG-конфигуратором оконных конструкций.

## Особенности проекта

- **Модель AIDA в дизайне и UX**:
  - **Sticky Header**: Парящая шапка поверх контента с компактным горизонтально раскрывающимся меню и быстрым скроллом к расчету.
  - **Hero-блок (Внимание)**: Атмосферный первый экран с архитектурной панорамой и проекцией чертежа.
  - **Технологии и производство (Интерес)**: Интерактивный разбор профиля (акустический триплекс 49 дБ, контур Passivhaus Uw 0.71, взломостойкость RC3).
  - **Реализованные проекты (Желание)**: Архитектурная галерея загородных резиденций с ветровыми расчетами и параметрами остекления.
  - **Интерактивный конфигуратор (Действие)**:
    - Резиновая SVG-схема окна на чистых стандартных векторных тегах без canvas и растровых наложений.
    - Прямое редактирование размеров на схеме в интерактивных плашках (инпуты, кнопки + / -).
    - Левая скроллируемая панель настроек (28-30% ширины) с логическими секциями-аккордеонами и карточками с отказоустойчивым `next/image` fallback.
    - Мгновенная обратная связь без перезагрузки и без кнопки «Применить».
    - Нижняя sticky-панель стоимости и модальное окно (Sheet) подробной сметы с детализацией надбавок.
  - **Контакты (Финальный захват)**: Форма прямой заявки с автоматическим прикреплением текущей конфигурации.

## Архитектура кодовой базы

- `components/`: UI-компоненты (директории `configurator/`, `landing/`, `layout/`, `ui/`).
- `lib/`: Независимая бизнес-логика (`lib/configurator/svg-geometry.ts` для математики чертежа, `lib/configurator/pricing.ts` для расчета стоимости).
- `utils/`: Универсальные функции (`formatCurrency`, `clampNumber`, `lerp`).
- `data/`: Каталоги типов окон, профильных систем Schüco/Natura/Kömmerling, стеклопакетов, цветов RAL/Wood, ручек Hoppe.
- `types/`: Строгая типизация TypeScript.
- `hooks/`: Централизованный Zustand-стор со срезами для предотвращения паразитных ререндеров.

## Запуск проекта

```bash
npm install
npm run dev
```
